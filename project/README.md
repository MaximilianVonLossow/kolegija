# Atsargų valdymo sistema

## Aprašymas
Tai C++ konsolės programa, leidžianti valdyti parduotuvės atsargas

## Tikslas
Projekto tikslas – įdiegti produktų inventoriaus sistemą su galimybe pridėti, redaguoti ir ištrinti duomenis.

## Funkcionalumas
Programa palaiko:

- Prekių pridėjimą
- Prekių peržiūrą
- Prekių redagavimą
- Prekių ištrynimą
- Rūšiavimą (pagal pavadinimą, kainą, kiekį)
- Ataskaitų generavimą

## Failai

- main.cpp — pagrindinis kodas
- products.txt — produkto duomenys
- report.txt — ataskaita

## Kaip paleisti

- 1. Paleiskite main.cpp su clion
- 2. Vykdykite meniu nurodymus
